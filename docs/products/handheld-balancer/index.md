# 手持均衡仪通则

线级共用页（安全、上位机安装通则等）。具体参数以型号页为准：

- [E04S05D](../e04s05d/) → https://docs.geekbms.com/products/e04s05d/
- [E06S05D](../e06s05d/) → https://docs.geekbms.com/products/e06s05d/

现行订货型号 **仅用** E04S05D / E06S05D（A 系列为旧型号）；HHB-\* 不是量产货号。

## 安全须知

- 锂电池操作有短路、起火、化学烧伤风险；注意极性与绝缘。
- 本产品为均衡维护工具，**不替代**电池管理系统（BMS）的保护功能。
- 超规格串数、电压或场合禁止使用；边界参数见各型号规格书。
- 认证与试验状态以各型号规格书为准，未获证不得宣传为已认证。

## 上位机通则

安装步骤、系统要求、通用菜单与升级方式：待软件工程师要点入库后补全。型号识别须与铭牌一致（E04 / E06 防错）。

## 包装与运输通则

包装清单、运输与贮存建议：待规格书 M10 齐套后从现行包引用。
