# 开始阅读

欢迎来到 GEEKBMS 技术文档中心。客户和工程师从这里找型号资料，或跳到开源 PACK 设计仓库。

公开网址：<https://docs.geekbms.com/getting-started/>

## 从这里开始

- [按型号](/products/)：保护板、主动均衡、手持均衡仪。每个型号有稳定地址 `/products/<id>/`。
- [电池 PACK 开源设计中心](/pack-design-hub/)：只做简介和导航。图纸、3D、BOM 在各自的 PACK 仓库里。

## 关于当前内容

阶段 1 的型号页是示例，用来占住公开路径。说明书和接线图发布后，在同一路径更新，不改网址。型号清单由仓库里的 `data/products.yaml` 人工维护，本阶段不接飞书 API。
