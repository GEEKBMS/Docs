# GEEKBMS Docs

公司 **技术文档中心**（面向客户与工程师的产品 / 应用知识库）源仓库。

官网站点：[geekbms-web](https://github.com/GEEKBMS/geekbms-web) · 设计导航登记：[Battery-PACK-Design-Hubs](https://github.com/GEEKBMS/Battery-PACK-Design-Hubs)

## 内容结构

### a. 电池 PACK 开源设计中心

路径：`docs/pack-design-hub/`

- 只做 **简介与导航**
- 具体型号资料在各自 PACK 仓库（例如 [motorcycle-battery-pack](https://github.com/GEEKBMS/motorcycle-battery-pack)）
- 与 GitHub 登记源 [Battery-PACK-Design-Hubs](https://github.com/GEEKBMS/Battery-PACK-Design-Hubs) 保持一致

### b. 产品技术文档

路径：`docs/products/`

- 闭源产品脱敏后可公开的规格书、应用说明等
- 按型号分子目录存放

## 本地预览（后续可接文档框架）

当前先以 Markdown 骨架为主。后续可接入 Starlight / VitePress 等静态文档工具，并部署到文档子域或挂到官网 `/docs/`。

```bash
# 暂无任意 Markdown 预览器打开 docs/ 即可
```
